## Prerequisites

### 1. Python Environment

- **Python 3.8+** installed and on PATH
- All dependencies installed:
  ```powershell
  pip install -r requirements.txt
  ```

### 2. PyInstaller

Install PyInstaller:
```powershell
pip install pyinstaller
```

Verify installation:
```powershell
pyinstaller --version
```

### 3. UPX (Optional - Recommended for Size Reduction)

UPX compresses the executable, reducing size by ~40%.

1. Download from: [https://github.com/upx/upx/releases](https://github.com/upx/upx/releases)
2. Extract `upx.exe` to a folder (e.g., `C:\Tools\upx`)
3. Add that folder to your system PATH

Verify installation:
```powershell
upx --version
```

### 4. Application Icon

The icon is automatically generated by `create_icon.py` during the build.

To generate it manually:
```powershell
python create_icon.py
```

## Quick Start

### One-Command Build

```powershell
.\build.ps1
```

This runs the full automated build pipeline:
- ✅ Validates Python and PyInstaller
- ✅ Cleans previous builds
- ✅ Generates application icon
- ✅ Runs PyInstaller with optimized settings
- ✅ Creates README and packages data files
- ✅ Outputs `dist\KeyloggerDetector.exe`

### Build Options

```powershell
# Full clean build (recommended)
.\build.ps1

# Incremental build (faster, skip clean)
.\build.ps1 -SkipClean

# Debug build (console window visible)
.\build.ps1 -Debug
```

## Detailed Build Process

### Step 1: Pre-Build Verification

Before building, ensure your source code is working:

```powershell
# Test main application
python main.py

# Test imports
python -c "from src.monitor import ProcessMonitor; from src.classifier import KeyloggerClassifier; print('✓ Imports OK')"
```

### Step 2: Review the Spec File

The `keylogger_detector.spec` file controls the build. Key settings:

```python
# What gets bundled
datas=[
    ('models/*.joblib', 'models'),       # Pre-trained ML models
    ('data/typing_baseline.json', 'data'), # Behavioral baselines
    ('data/whitelist.json', 'data'),       # Whitelist
]

# Hidden imports (packages PyInstaller might miss)
hiddenimports=[
    'sklearn', 'psutil', 'tkinter', 'pynput', 'flask', ...
]

# Excluded modules (to reduce size)
excludes=[
    'matplotlib', 'scipy', 'pandas', 'pytest', ...
]

# Build mode
console=False,    # Windowed mode (no console)
icon='icon.ico',  # Application icon
upx=True,         # Enable UPX compression
```

### Step 3: Run the Build

#### Using the Build Script (Recommended)

```powershell
.\build.ps1
```

#### Using PyInstaller Directly

```powershell
pyinstaller keylogger_detector.spec --clean
```

### Step 4: Build Output

After a successful build:

```
dist/
  ├── KeyloggerDetector.exe     ← Your standalone executable
  ├── README.txt                ← First-run instructions
  └── models_optional/          ← Pre-trained model (if exists)
      └── keylogger_detector.joblib
```

**File size expectations:**
- With UPX: ~45-60 MB
- Without UPX: ~70-90 MB

## Testing the Executable

### Basic Launch Test

```powershell
.\dist\KeyloggerDetector.exe
```

Expected behavior:
1. **First run:** Creates `%LOCALAPPDATA%\KeyloggerDetector\` and subfolders
2. **GUI opens:** Dashboard window appears
3. **System tray icon:** Appears in notification area
4. **Monitoring starts:** Background process scanning begins

### Test Command-Line Options

```powershell
# Show help
.\dist\KeyloggerDetector.exe --help

# Start minimized to tray
.\dist\KeyloggerDetector.exe --minimized

# Headless mode (no GUI)
.\dist\KeyloggerDetector.exe --no-gui

# Custom scan interval
.\dist\KeyloggerDetector.exe --scan-interval 10
```

### Verify Data Persistence

1. Run the executable
2. Close it
3. Check that files were created:
   ```powershell
   dir $env:LOCALAPPDATA\KeyloggerDetector
   ```

Expected structure:
```
%LOCALAPPDATA%\KeyloggerDetector\
  ├── models\
  │   └── keylogger_detector.joblib          (if copied manually)
  ├── logs\
  │   ├── detector.log                       (application log)
  │   └── keylogger_events.db                (SQLite database)
  ├── data\
  │   ├── whitelist.json                     (user whitelist)
  │   ├── typing_baseline.json               (behavioral baseline)
  │   └── mouse_baseline.json
  └── quarantine\                            (quarantined executables)
```

### Test Single-Instance Enforcement

1. Run `KeyloggerDetector.exe`
2. Try running it again
3. **Expected:** Message box: *"Keylogger Detector is already running"*

### Check Logs for Errors

```powershell
notepad $env:LOCALAPPDATA\KeyloggerDetector\logs\detector.log
```

Look for:
- ✅ `"DBLogger initialised"`
- ✅ `"Monitor started"`
- ✅ `"BehavioralAnalysisEngine started"`
- ❌ Any `ERROR` or `CRITICAL` messages

## Distribution

### Creating a Distributable Package

**Option 1: Single EXE (simplest)**

Just distribute `KeyloggerDetector.exe`. Users double-click to run.

**Option 2: ZIP Package**

Create a ZIP file containing:
```
KeyloggerDetector/
  ├── KeyloggerDetector.exe
  ├── README.txt
  └── models_optional/
      └── keylogger_detector.joblib
```

PowerShell to create ZIP:
```powershell
Compress-Archive -Path dist\* -DestinationPath KeyloggerDetector-v1.0.0.zip
```

### Installation Instructions for End Users

Include these instructions with your distribution:

```markdown
# Installation

1. Extract the ZIP file (if packaged)
2. Double-click `KeyloggerDetector.exe`
3. (Optional) Create a desktop shortcut

# First Run

On first launch, the application will:
- Create `%LOCALAPPDATA%\KeyloggerDetector\`
- Generate empty database and log files
- Start in heuristic mode (until you train a model)

# Optional: Install a Pre-Trained Model

If you have a pre-trained model:
1. Run KeyloggerDetector.exe once (to create folders)
2. Copy `keylogger_detector.joblib` to:
   `%LOCALAPPDATA%\KeyloggerDetector\models\`
3. Restart the application

# Uninstallation

1. Close KeyloggerDetector.exe (right-click tray icon → Quit)
2. Delete the executable file
3. (Optional) Remove user data: `%LOCALAPPDATA%\KeyloggerDetector\`
```

### Code Signing (Optional but Recommended)

To avoid Windows SmartScreen warnings, sign the executable:

1. Obtain a code-signing certificate
2. Sign with `signtool.exe`:
   ```powershell
   signtool sign /f cert.pfx /p password /t http://timestamp.digicert.com dist\KeyloggerDetector.exe
   ```

## Troubleshooting

### Build Errors

#### Error: "PyInstaller not found"

**Solution:**
```powershell
pip install pyinstaller
```

#### Error: "Module not found: sklearn / psutil / tkinter"

**Solution:**
```powershell
pip install -r requirements.txt
```

#### Error: "icon.ico not found"

**Solution:**
```powershell
python create_icon.py
```

#### Error: "RecursionError during build"

**Solution:** Add to spec file:
```python
import sys
sys.setrecursionlimit(5000)
```

---

### Runtime Errors

#### Error: "Failed to execute script main"

**Cause:** Missing hidden imports or runtime dependencies.

**Diagnosis:**
1. Build with debug mode:
   ```powershell
   .\build.ps1 -Debug
   ```
2. Run the debug executable and read console output
3. Add missing imports to `hiddenimports=[]` in spec file

#### Error: "Database is locked"

**Cause:** Multiple instances running.

**Solution:** The single-instance mutex should prevent this. If it occurs:
- Kill all `KeyloggerDetector.exe` processes
- Check Task Manager for orphaned processes
- Restart

#### Error: "Permission denied" when quarantining a process

**Cause:** Insufficient privileges.

**Solution:**
- Run as Administrator for full process control
- Or: Whitelist protected system processes

---

### Performance Issues

#### Large EXE Size (>100 MB)

**Solutions:**
1. Install UPX (see Prerequisites)
2. Add more exclusions to spec file:
   ```python
   excludes=['matplotlib', 'scipy', 'pandas', 'IPython', ...]
   ```
3. Use `--onedir` mode instead of `--onefile` (faster startup, but creates a folder)

#### Slow Startup Time

**Causes:**
- UPX decompression on first load (2-3 seconds)
- Antivirus scanning the unpacked files

**Workarounds:**
- Add `%TEMP%\_MEI*` to antivirus exclusions
- Use `--onedir` mode
- Consider using `--noupx` if startup speed is critical

### Building for Different Architectures

**32-bit:**
```powershell
pyinstaller keylogger_detector.spec --target-arch=x86
```

**64-bit (default):**
```powershell
pyinstaller keylogger_detector.spec --target-arch=x64
```

### Creating an Installer

Use **Inno Setup** to create a Windows installer:

1. Download: [https://jrsoftware.org/isinfo.php](https://jrsoftware.org/isinfo.php)
2. Create an `.iss` script:
   ```iss
   [Setup]
   AppName=Keylogger Detector
   AppVersion=1.0.0
   DefaultDirName={pf}\KeyloggerDetector
   OutputBaseFilename=KeyloggerDetector-Setup
   
   [Files]
   Source: "dist\KeyloggerDetector.exe"; DestDir: "{app}"
   
   [Icons]
   Name: "{commondesktop}\Keylogger Detector"; Filename: "{app}\KeyloggerDetector.exe"
   ```

### Continuous Integration

For automated builds in CI/CD:

```yaml
# GitHub Actions example
name: Build
on: [push]
jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      - run: pip install -r requirements.txt
      - run: pip install pyinstaller
      - run: .\build.ps1 -SkipClean
      - uses: actions/upload-artifact@v2
        with:
          name: KeyloggerDetector.exe
          path: dist/KeyloggerDetector.exe
```
